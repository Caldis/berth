# 描述
- 增加项目切换器, 让应用除了全局视图外, 还能切换到用户域或具体项目域。
- 切换后应独立检视该项目的会话、配置、能力、hooks、skills、MCP、用量等内容。

# 重现步骤
- 打开当前应用。
- 尝试在全局视图之外选择某个项目, 并查看项目级配置与资产。

# 预期结果
- 用户可以在全局、用户域和项目域之间切换。
- 当前选择的项目范围会影响页面数据查询和配置展示。
- 项目切换器应在应用壳中有固定入口, 不应藏在设置深处。

# 实际结果
- 当前主要是全局视图, 项目维度能力不完整。

# 解决方案
- 先定义 scope 模型: global / user / project。
- 梳理各页面数据源是否支持项目过滤。
- 将项目入口与本地来源管理合并设计, 避免设置页和主导航重复。
