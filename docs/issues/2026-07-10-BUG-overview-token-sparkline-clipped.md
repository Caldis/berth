# 描述
- 总览「概览」widget 的「累计 TOKEN」统计下方出现一段残缺的迷你折线 (形似 `____/`, 只有末端一小段上翘), 视觉上像渲染裁剪或数据域计算异常, 其余统计项无此装饰 (2026-07-10 本机实测截图, 两次巡检均复现)。

# 重现步骤
- 本机有历史用量数据, 打开 Berth 总览页, 查看「概览」widget 第一项。

# 预期结果
- sparkline 完整绘制趋势 (或该项与其它统计一致不带 sparkline)。

# 实际结果
- 折线大部分区段贴底为直线, 末端突兀上翘, 观感为残缺/裁剪。

# 解决方案
- 先根因定位: 检查该 sparkline 的数据窗口与 y 域 (累计值单调递增时用累计序列画 sparkline 必然前平后翘, 应改用每日增量序列或移除)。
