# 描述
- 首页总览需要完全重构为新版本设计。
- 当前首页无法承担 1.0 版本的入口页质量要求。

# 重现步骤
- 打开应用首页。
- 查看总览信息架构、视觉层级、健康状态、项目入口和高频操作。

# 预期结果
- 首页能清楚回答当前 agent / 项目 / 健康 / 最近活动 / 待处理事项。
- 视觉风格成熟, 与新的 app shell、项目切换器和侧边栏一致。
- 首页不堆砌解释性文本, 但关键状态可追溯。

# 实际结果
- 当前首页仍是旧设计, 信息组织和视觉质量需要重做。

# 解决方案
- 先基于新 app shell 和项目范围模型定义首页职责。
- 设计可验证的信息结构和状态组件。
- 做桌面实测截图验收, 覆盖空数据、正常、警告、加载和错误状态。
