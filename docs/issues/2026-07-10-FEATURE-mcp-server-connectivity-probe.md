# 描述
- MCP 页所有 server 状态列恒为「未知」(Berth 只静态读配置, 从不探测), 状态列信息量为零 (2026-07-10 本机实测 7 条全部「未知」)。用户最关心的其实是"这个 server 现在能不能连上/命令是否存在"。

# 重现步骤
- 配置任意 MCP server, 打开 Berth MCP 页。

# 预期结果
- 提供轻量连通性探测: 至少校验 command 可执行文件存在 (PATH 解析) / URL 可达; 理想态支持手动触发 "测试连接" (spawn + MCP initialize 握手, 超时即 failed), 状态列显示 connected/failed/未测。

# 实际结果
- 状态列恒为「未知」。

# 解决方案
- 分两级落地: ① 扫描期静态校验 command 存在性 (无副作用, 默认开); ② 卡片级手动"测试连接"按钮走主进程 spawn 探测 (显式用户触发, 避免自动拉起任意命令的安全面)。探测属于运行外部命令, 需要权限/安全评估。
