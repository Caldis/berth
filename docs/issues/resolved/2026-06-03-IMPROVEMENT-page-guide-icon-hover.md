# 描述
- 顶部导航栏的页面说明按钮占用过多空间, 需要改为图标按钮并通过 hover 展示说明内容。

# 重现步骤
- 打开带页面说明的功能页, 例如会话或记忆页。
- 查看顶部导航栏右侧的页面说明按钮。
- 将鼠标移到说明按钮和说明叠层上。

# 预期结果
- 导航栏只显示 `?` 图标按钮。
- 按钮仍有可访问名称。
- hover / focus 时展示说明叠层。
- 鼠标从按钮移动到叠层时, 说明内容保持可见。

# 实际结果
- 按钮显示 `? 页面说明`, 占用导航栏横向空间。
- 说明叠层通过 click 切换, 不符合 hover 展示需求。

# 解决方案
- `TopNavigation` 中页面说明按钮改为 `h-9 w-9` 图标按钮。
- pointer/focus 触发说明叠层。
- 离开触发区域后延迟关闭, 进入叠层会取消关闭计时。
- 说明叠层放在同一 hover 区域内, 并用 `top-full pt-2` 连接按钮与叠层。
- renderer 测试覆盖按钮无可见文字、hover 展示、移入叠层后保持展示。
