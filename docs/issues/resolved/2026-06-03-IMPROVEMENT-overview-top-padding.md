# 描述
- 首屏总览没有顶部导航栏后, 主内容顶部贴近窗口边缘, 需要增加合适的顶部留白。

# 重现步骤
- 打开应用首页总览。
- 查看总览 hero 卡片与窗口顶部之间的距离。

# 预期结果
- 总览不显示顶部导航栏。
- 总览主内容与窗口顶部之间保留与页面水平留白一致的距离。

# 实际结果
- 总览主内容外壳使用 `pt-0`, hero 卡片顶部贴近窗口边缘。

# 解决方案
- 总览 route 内容外壳改为 `pt-6`, 与 `px-6` 的 24px 页面边距一致。
- `tests/renderer/app-layout.test.tsx` 覆盖总览无导航栏但保留顶部留白, 并确认功能页内容区仍位于独立滚动区。
