# 描述
- Sessions 渐进渲染进度提示显示在筛选栏和列表之间, 提示出现或隐藏时会改变页面流高度, 导致列表位置抖动。

# 重现步骤
- 打开 Sessions 页面。
- 在会话数量较多时等待渐进渲染提示从“Showing n of total sessions”消失。

# 预期结果
- 渐进渲染或后台刷新状态可见, 但状态变化不改变列表和筛选栏之间的布局高度。

# 实际结果
- 状态提示作为独立区块插入页面流, 隐藏后列表向上移动。

# 解决方案
- 将 Sessions 的后台刷新和渐进渲染提示合并到筛选工具栏内的固定状态槽。
- 状态槽保持固定尺寸, 提示内容只在槽内变化, 不新增或移除列表上方的页面高度。
- 完成日期: 2026-06-03。
