# 描述
- 重构应用外壳, 将顶部导航、左侧边栏和窗口控制区对齐 `D:\Code\bobcorn` 的交互结构。
- 左侧边栏需要支持 hover 后拖曳调整宽度, 顶部有折叠按钮。
- 右侧顶部需要有独立分割线导航栏, 展示当前路由面包屑。
- 右上角三个窗口控制按钮需要正确布局, 并支持 pin 功能。

# 重现步骤
- 打开当前应用任意页面。
- 查看左侧边栏、顶部路由区域和右上角窗口控制区。
- 与 `D:\Code\bobcorn` 的应用壳布局进行对比。

# 预期结果
- 应用外壳具备稳定的左侧导航、顶部路由面包屑、窗口控制和 pin 交互。
- 左侧边栏可折叠、可按合理范围调整宽度。
- 布局在常用桌面尺寸下不挤压页面主体内容。

# 实际结果
- 当前应用壳还没有 bobcorn 风格的可调宽边栏、独立面包屑导航和完整窗口控制布局。

# 解决方案
- 先探索 bobcorn 的布局实现和当前 berth 的 app shell 结构。
- 提炼可复用 shell 组件, 再迁移现有页面入口。
- UI 验收必须覆盖折叠、拖曳、pin、面包屑、窗口控制按钮和页面主体宽度变化。
