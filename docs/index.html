Berth

See everything your AI agents have installed — skills, MCP servers, hooks, sessions, and costs — in one clean desktop app.

Download GitHub

macOS & Windows · Read-only · No telemetry · MIT License

Your AI agent assets are invisible

Claude Code, Codex, and Cursor install skills, MCP servers, hooks, and configs as plain-text files scattered across your machine. They're powerful but invisible — installed and forgotten.

👁️

Visibility

See all 25+ asset types at a glance. Skills, MCP servers, hooks, plugins, sessions, costs.

🔗

Relationships

Understand how assets connect. Which skills were used in a session? What does this plugin contain?

📊

Observability

Track token usage, costs per model, rate limits, and health checks across all your sessions.

Features

🏠 Overview Dashboard

Stat cards, recent sessions, cost charts, and health checks in one view.

💬 Session Browser

Browse all sessions grouped by project, with loaded skills, MCP servers, and artifacts.

📝 Instructions

Skills, memories, commands, subagents, output modes, and agent teams — all in tabs.

⚡ Capabilities

MCP servers with scope merge, hooks by event, plugins, permissions with bypass warnings.

📈 Usage Analytics

Daily cost charts, token usage by model and project, rate limit monitoring.

🔍 Global Search

⌘K to search across all assets by name, type, or scope. Full-text search powered by MiniSearch.

🌐 i18n

Full English and Chinese interface support.

🌓 Dark Mode

Light, dark, or system theme with navy + warm orange accent palette.

Quick Start

# Clone and run
git clone https://github.com/Caldis/berth.git
cd berth
pnpm install
pnpm dev

Or download the installer from Releases.
