# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源: 用户会话, 2026-05-30。

## 原始描述

用户要求修复设置里的“扫描目录”功能:

- 当前设置里有一个扫描目录功能。
- 这个功能目前默认指定的是 Claude 的用户目录。
- 但“会话”里现在已经包括 Codex 会话, 也包括所有项目级别会话。
- 也就是说当前扫描目录展示的 Claude 目录, 与实际扫描结果范围不一致。
- 需要从头分析项目如何扫描所有 Agent 相关资产。
- 需要确认设置里“扫描目录”列出的 Claude 目录在实际逻辑里如何生效。
- 需要判断优化设计时, 设置里这个选项应该如何调整。
- 也需要判断是否根本不需要告诉用户扫描目录, 因为应用目标是列出本机所有 Agent 相关资产, 不管它在什么目录。

## 复现步骤

1. 打开应用设置。
2. 查看“扫描目录”区域。
3. 对比“会话”页中已经出现的 Codex 会话和项目级会话。

## 期望 vs 实际

- 期望: 设置说明与真实扫描范围一致, 不把产品误表述成只扫描 Claude 用户目录。
- 实际: 设置仍展示 Claude 用户目录作为默认扫描目录, 容易让用户误解当前资产发现边界。
