# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源:

用户反馈: “现在左侧边栏的搜索和页面顶部 header 的搜索，两个快捷键是一样的，请你让它们两个快捷键做出区分”

## 复现步骤

1. 打开任意带左侧边栏和顶部 header 页面。
2. 查看左侧边栏全局搜索输入框的快捷键提示。
3. 查看页面顶部 header 的页面内搜索输入框快捷键提示。
4. 使用当前快捷键尝试触发搜索。

## 期望 vs 实际

- 期望: 左侧全局搜索和页面顶部页面内搜索使用不同快捷键, 用户可以明确知道每个快捷键触发哪个搜索入口。
- 实际: 两个搜索入口目前使用相同快捷键, 造成键盘交互冲突和提示混淆。
