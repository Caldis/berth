# PRD 快照 (只读)

> 原始 PRD 的快照。任何阶段不回写。来源链接/页面 ID 记于此。

来源: 用户会话内需求 (2026-06-11) + GitHub Issue https://github.com/Caldis/berth/issues/120

## 正文

请优化 [会话] 下的详情页中的 [重放] 模块, 本次优化聚焦于视觉效果设计和交互:

- 每种事件应有独立的图标 (目前已经有), 和主题颜色
- 顶部的事件筛选器应和图标关联, 且 Check 不应在最右, 而是在左侧
- 顶部时间轴使用 canvas 重新绘制和设计, 类似 Chrome Dev Tools 中的 Performance 面板中的时间轴的高性能和流畅交互设计, 并允许鼠标滚动进行缩放, 左右拖曳进行导航, 便于定位事件细节, 且顶部时间轴有一个 "window" 样式的矩形区域会同步展示底部的事件列表所在时间轴中的位置
- 顶部的时间轴应和事件主题色关联, 如果事件之间有长时间等待 (例如等待用户输入) 或用户中断 (例如用户按下 Esc) 也应该有对应的样式进行呈现
- 顶部的时间轴的定位胶囊移除, 改为将用户选中的事件进行框选和高亮
- 右侧面板应支持拖曳调整宽度, 点击放大到全屏, 以及导出功能

附加约束: 用户显式调用 `/frontend-design`, 设计与实现阶段以 frontend-design 方法 (大胆而有意图的美学方向、避免 AI slop、高性能动效) 为参考。
