# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源: `docs/issues/2026-06-02-BUG-global-search-usability.md`

## 描述
- 当前搜索功能不可用或可用性很差, 用户无法依赖它找到目标内容。

## 复现步骤
- 打开全局搜索。
- 输入已知存在的会话、配置、命令、技能或 MCP 关键词。

## 期望 vs 实际
- 预期: 搜索能覆盖主要实体, 返回可点击、可辨识来源的结果。
- 预期: 空结果、加载和错误状态清楚。
- 预期: 键盘操作可用。
- 实际: 当前搜索被用户判断为“完全是废的”。

## 初始解决方向
- 先审计搜索索引、查询入口和结果 UI。
- 定义搜索范围: sessions / projects / configs / hooks / skills / MCP。
- 从一个高价值范围开始修复, 再扩展到其他实体。
