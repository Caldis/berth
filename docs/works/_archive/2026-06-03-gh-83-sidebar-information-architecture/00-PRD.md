> 原始 PRD 的快照。任何阶段不回写。

来源: docs/issues/2026-06-02-FEATURE-sidebar-information-architecture.md

## 正文

# 描述
- 重构侧边栏信息架构。
- 当前侧边栏聚合了指令、能力、用量等大模块, 页面内部又有功能 tab。
- 需要取消页面内主要功能 tab, 将高频页面提升为一级菜单, 同时保留清晰归类和简短介绍。
- Agent 类型切换也需要重新设计位置。

# 重现步骤
- 打开当前应用。
- 在指令、能力、用量等页面中查看页面内 tab 和侧边栏分组。

# 预期结果
- 高频页面作为一级菜单出现, 侧边栏带简短说明。
- 页面内不再用大 tab 承担主导航职责。
- Agent 类型切换位置符合实际使用路径, 不干扰项目切换。

# 实际结果
- 当前侧边栏和页面内 tab 的边界不清晰, 用户需要在多层导航里找功能。

# 解决方案
- 先做页面清单和使用路径审计。
- 设计新的一级菜单分组、文案和 agent 切换位置。
- 实现时应避免一次迁移所有页面导致回归, 可先迁移一个完整分组。
