## 正文

用户希望在上一轮会话详情页优化完成后, 继续按新的信息架构推进:

- 将“概览”和“会话信号”放在一个 tab。
- 将“工具时间线”放在一个 tab。
- 将“产物”放在一个 tab。
- 拆分后页面可以容纳更多有意义的调试功能, 避免当前详情页继续纵向堆叠。
- 当前任务要求: 先归档已有 session detail agent observability 任务, 再以 tabbed detail page 为目的开展新的设计任务。

约束:

- 本阶段先做设计任务, 不直接实现 UI。
- 新设计应延续上一轮已完成的工具筛选、模型信息 tooltip、checkpoint 摘要、全宽产物区和高密度时间线能力。
- 目标用户是 Agent 开发者, 需要快速定位失败工具、慢工具、token/cache/cost 异常和可复盘的产物证据。
