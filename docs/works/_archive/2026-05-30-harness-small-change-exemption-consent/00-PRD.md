# PRD 快照 (只读)

> 原始 PRD 的快照。任何阶段不回写。来源链接/页面 ID 记于此。

来源: 用户在本会话中纠正侧边栏间距修复未走 harness 的处理方式。

## 正文

用户先问: “你为什么本次没有走 harness 流程”

Agent 解释为误用“小改动豁免”, 并记录 friction。

用户随后纠正:

> 不不, 这是合理的, 但是你应该主动声明这个是小改动然后向用户申请豁免, 而不是直接进入豁免流程
> 请修正

Agent 已修正 friction 记录。用户进一步要求:

> 请将这个摩擦实际落实到 harness 框架中

目标: 将“小改动豁免需要先主动声明并征得用户同意”的规则写入 harness 框架, 让后续 Agent 在跳过 opsx-new 前有明确、可执行的判断和沟通要求。
