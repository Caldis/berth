# Berth v0.1 Development Plan

## Tech Stack
- **Runtime**: Electron 33 (electron-vite 5)
- **Frontend**: React 19 + TypeScript 5.9
- **UI**: Tailwind CSS 3.4 + lucide-react
- **State**: Zustand 5
- **i18n**: i18next + react-i18next (en/zh)
- **Router**: react-router-dom 7 (MemoryRouter)
- **Search**: MiniSearch
- **Storage**: better-sqlite3
- **File Watch**: chokidar 4
- **Testing**: Vitest + Playwright
- **Package Manager**: pnpm
