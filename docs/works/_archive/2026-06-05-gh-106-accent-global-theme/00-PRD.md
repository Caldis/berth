# PRD 快照 (只读)

> 原始输入的快照。任何阶段不回写。

来源: 用户会话反馈 (2026-06-05) + 设置面板截图。GitHub Issue: Caldis/berth#106。延伸自 #105 (accent picker 来源)。

## 正文

### 原始反馈
- 截图: 设置 > Appearance > Accent color, 5 个圆形色块 (蓝[选中] / 紫 / 绿 / 橙 / 红)。
- 用户原话: "目前 accent color 选项中没有我们默认的黑色, 且选择之后没有如实反映在整个 UI 上, 我们是否缺乏了统一的主题管理器?"

### 诊断结论 (会话已查清, 详见 01-ANALYSIS)
- 统一主题管理器存在 (`components/theme-provider.tsx`), 非缺失。
- 根因: `--primary` (品牌主色, 默认蓝, picker 驱动) 与 `--accent` (中性强调色, 黑, picker 不碰) 两个 token 分离; 切换只影响 CTA / 图表 / focus ring 等小范围, 占视觉主导的中性黑导航 / 强调不变, 故"选了不生效"。黑色被固定为 `--accent`, 不在 picker 候选, 故"没有黑色"。

### 方向确认 (AskUserQuestion, 2026-06-05 — 用户选定)
目标形态 = **全局主题色 + 默认中性黑** (三选一中确认):
1. accent picker 升级为贯穿全 UI 的主题色: 导航选中、强调等当前走 `--accent` 的中性 token 接入 picker 驱动。
2. 新增"中性黑"为第 6 个 accent, 并设为默认 (默认主色从蓝改中性)。
3. 默认态保持现有中性观感 (CTA / focus 也归中性); 切到彩色时全局强调跟随, 做到"选什么色整个 UI 可见"。
4. 接受调整 GH-105 "导航保持中性" 的设计前提。

### 验收意图 (待 design 细化为可测条目)
- 设置面板 accent 选项包含"中性黑"且为默认选中项。
- 切换 accent 后, 导航选中态与主要强调元素颜色随之变化 (全 UI 范围可见, 非仅 CTA / focus)。
- 默认 (中性黑) 下整体观感与当前一致, 无突兀彩色; 浅色 / 深色两套主题下均成立。
- 既有 5 个彩色 accent 切换不回归。
