# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源:
https://github.com/Caldis/berth/issues/38

## 描述

中文界面里仍有少量英文标签直接露出, 影响设置页和能力说明的一致性。

## 复现步骤

1. 切换到中文界面。
2. 打开设置弹窗, 查看插件区标题。
3. 打开能力页, 查看功能说明中的统计 tag。

## 期望 vs 实际

期望:
- 中文 locale 下这些 UI 标签使用中文表达, 例如 "Agent 能力插件"、"提供方"。

实际:
- 设置弹窗中的插件区标题显示为 `Agent Capability Plugins`。
- 能力说明的统计 tag 显示 `provider`, 例如 `1 个 provider`。
- 同一区块其他文案已经是中文, 因此这些英文标签属于 i18n 漏翻。
