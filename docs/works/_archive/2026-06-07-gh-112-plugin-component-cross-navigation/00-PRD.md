# PRD 快照 (只读)

> 原始 PRD 的快照。任何阶段不回写。

来源: 用户请求 (GitHub Issue #112)

## 用户原话
> 目前我们有一些 mcp/hooks/skill/agent... 等能力是 plugin 提供的, 我们在 UI 上需要标识出其关联, 并提供在不同页面间一键跳转的能力, 反之亦然.

## 解读
- **标识关联 (双向可见)**: 插件提供的组件 (skill/mcp/hook/agent/command/output-mode 等) 在其所在的类目页面显式标注"来自插件 X"; 插件页已按 pluginId 归组展示组件 (GH-110 P4.2)。
- **一键跳转 (双向)**:
  - 组件页 → 插件页: 点击组件的"来源插件"徽标 → 跳到插件页并定位/高亮/展开该插件。
  - 插件页 → 组件页: 点击插件卡片里的组件项 → 跳到该组件所在类目页并定位/高亮/展开该组件行。

## 现状锚点 (待 explore 核实)
- 组件已带 `meta.pluginId` / `meta.origin='plugin'` (GH-110 P2.2 插件下钻)。
- 插件页 PluginCard 已按 pluginId 归组 (GH-110 P4.2)。
- 需新增: 组件页来源插件徽标 + 双向跨页跳转 (deep-link + scroll/highlight/expand 定位) 基础设施。

## 验收要点
- 各组件页对 plugin-origin 组件显示来源插件徽标 (HeroUI) + 可点击跳转。
- 插件页组件项可点击跳转到组件页并定位高亮。
- 双向、跨页、含定位高亮; 有测试; 界面质量 (徽标视觉/跳转反馈/高亮态) 验收。
