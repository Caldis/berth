# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源: 用户在 2026-05-30 提出

## 复现步骤
1. 用户自己运行 `npm run dev` / `pnpm dev` 查看当前应用状态。
2. Agent 在 harness 流程中为了调试或验收，也主动启动 Electron dev 实例。
3. 两个 dev 实例互相冲突；验收结束后，Agent 清理进程时可能把用户自己的 dev 实例一起杀掉。

## 期望 vs 实际
期望:
- Agent 调试时不要接管用户当前正在使用的 dev 实例。
- Agent 自己创建独立实例做调试和验收。
- 验收完成后，Agent 只清理自己管理的实例。
- 用户自己的 dev 实例继续运行，并能同步刷新到最新应用内容。

实际:
- Agent 启动/清理 Electron dev 进程时没有可靠区分进程归属。
- 用户手动启动的 dev 实例可能被误杀。
