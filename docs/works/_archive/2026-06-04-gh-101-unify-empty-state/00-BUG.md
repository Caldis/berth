# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源: 用户报告 (GH-101) — 附 4 张截图

## 复现步骤
1. 打开应用, 进入任意存在空态的页面 (session-detail / memory / instructions / sessions / overview)。
2. 观察空态样式: 堆叠卡片占位图 + 圆角虚线框, 但占位组件贴在内容区顶部, 框未撑满内容区, 整体未垂直居中 (截图 1/2/3)。
3. 进入 capabilities 页面 (如 MCP / 状态栏标签页空态)。
4. 观察空态样式: 单个大图标 + 文字, 与上一种明显不同 (截图 4)。

## 期望 vs 实际
- 期望:
  1. 全站空态使用统一的单一样式 (单一共享组件)。
  2. 空态圆角虚线矩形撑满所在内容区。
  3. 占位图 (placeholder) 在内容区内垂直、水平都居中。
- 实际:
  - 存在两套空态实现 — 共享 `components/shared/empty-state.tsx` (堆叠卡片占位图) 与 `pages/capabilities.tsx` 本地同名 `EmptyState` (单图标), 视觉不一致 (同名遮蔽)。
  - 共享组件用固定 `px-6 py-14` 内边距, 不撑满内容区, 贴顶显示, 无法整体垂直居中。
