## 正文

用户认可以下 Health Checks 后续改进方向, 并要求开启子代理、基于 Codex 与 Claude Code 官方文档整理方案并落地:

1. 用官方 schema 做更准的配置校验。
2. 降低误报, 尤其区分当前平台、团队跨平台配置和只读诊断边界。
3. 健康检查和资产页深度跳转, 点一条检查能定位到对应 MCP / hook / skill / agent。
4. 每条检查带“为什么报这个”的证据, 包含官方来源、读取字段、缺失字段。
5. 支持 WSL / Windows 双 home 或额外 agent home 显式配置, 不自动猜路径。
6. 只读前提下补修复建议模板, 如打开文件定位或提供可复制配置片段。
7. 健康检查随文件变更增量刷新, 显示 last checked 时间并只重算相关来源。

约束:

- 继续支持 macOS 与 Windows。
- 继续支持 Codex 与 Claude Code。
- 以官方文档为依据；外部产品行为、字段契约、配置格式必须先查 official docs。
- 当前仓库存在其他 agent 的脏改动, 本任务必须缩小改动面, 只提交本任务相关文件。
