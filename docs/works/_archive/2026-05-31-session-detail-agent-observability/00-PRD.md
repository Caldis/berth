# PRD 快照 (只读)

来源: 用户在 2026-05-31 的会话请求。

## 正文

用户希望优化「会话」里的详情页，范围包括：

- UI/UX，按 `frontend-design` 风格要求做更好的界面。
- 时间线左侧设计：当前每个线段没有连在一起，图标没有对齐。
- 工具调用时间线现在只输出时间节点，希望改成更有用的调试信息，例如每个工具调用耗时，并参考 Anthropic 或 OpenAI Agent Console Debug / tracing 的思路。
- 思考除工具调用时间线之外，还能输出什么对 Agent 开发者有用的信息。
- 借鉴 OpenClaw 一类整体应用指标：消息数量、吞吐量、工具调用、缓存命中率、错误数量/率、平均成本，并尝试做得更好。
- 说明页面里「时长」目前如何计算。
- token 汇总区存在冗余字段，上面纯文字和下面 Legend 同时出现，希望只保留更好看的一个。
- 优化整体排版，避免纯垂直罗列，提高信息利用率，让用户更容易找到重点。
