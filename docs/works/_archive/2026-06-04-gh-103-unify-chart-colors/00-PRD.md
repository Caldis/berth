来源: 用户反馈 (2026-06-04, 含 4 张图表截图) · GitHub Issue #103

## 正文

需求: 统一应用内所有图表配色, 选择美观、符合应用风格的主题配色。

四处图表现状与用户评价:

1. **会话详情页内图表** — 「这个好」。作为统一配色的**参考标准 / 真源**。
2. **首页「近 7 天费用」柱状图** — 「这个很丑」。配色为黑 / 灰 / 蓝灰 / 青绿 / 玫红混搭, 无主题感, **重点改造对象**。
3. **用量页内 TOKEN 用量分段条** — 「可保留」(蓝=输入 / 绿=输出 / 橙=缓存 / 紫=推理, 语义色)。需纳入统一体系。
4. **用量页内「每日花费」柱状图** — 「可保留」(纯黑/深灰柱)。需纳入统一体系。

验收基调:
- 配色美观且与应用整体风格一致。
- 以会话详情页图表配色为基准向其余图表收敛。
- 「可保留」的两处保留语义可辨识性, 但应统一到同一套主题 token, 而非各自硬编码。
- 重点修复首页近 7 天费用柱状图的杂乱配色。
