# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源:

- GitHub Issue: https://github.com/Caldis/berth/issues/97
- 用户截图与描述: 记忆页标签过多; 原始文件查看器右上角控件与系统窗口按钮层级/位置冲突。

## 复现步骤

1. 打开 Berth 的“记忆”页。
2. 在标签数量较多时查看标签筛选区。
3. 展开一条记忆，点击“查看原始文件”。
4. 在 Windows 下观察右侧查看器顶部关闭按钮与窗口控制按钮的位置; 在 macOS 下观察窗口控制按钮可否正确获得焦点。

## 期望 vs 实际

- 期望: 标签默认只占一行; hover 后用浮层展示全部标签，浮层可滚动，不挤压或遮挡下方正常内容。
- 期望: 原始文件查看器的关闭按钮不与系统窗口控制按钮重叠; macOS 系统窗口控制按钮可正确获得焦点。
- 期望: 原始文件查看器被抽成公共组件，在需要查看文件内容的入口复用，并支持用户拖曳调整宽度。
- 实际: 标签区多行铺开，挤压下方内容; 原始文件查看器顶部控件与系统窗口按钮有层级和位置冲突; 当前查看器能力还没有形成可复用的文件查看组件。
