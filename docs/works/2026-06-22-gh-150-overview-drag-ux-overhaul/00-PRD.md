## 正文

### 用户诉求 (原话)
> 我们来优化 [总览] 部分的拖拽体验。

随后补充的四个具体体验问题:
1. **拖的时候很卡帧数很低不跟手, 我需要极致的性能优化。**
2. **添加 widget 之后出现在页面最底部但是滚动锚点不会自动同步和聚焦, 用户不知道新增了哪个小组件。**
3. **有的时候内容会变形, 但是我不知道触发机制, 反正有时候拖拽会有时候不会。** (用户假设: 看起来是它和一个和当前 size 不一样的组件交换位置之后, 它就会按目标组件去 resize, 但这不对。附截图: 编辑态拖拽 "累计增长" widget 时, 浮动的 "TOKEN 强度" 列表卡片字母被横向拉伸变形。)
4. **即便是瀑布流, 我认为所有小组件应该有几组固定高度和宽度这样便于布局填空, 且都需要为固定的整数倍这样不会产生空隙。**

### 用户已确认决策 (AskUserQuestion, 2026-06-22)
- **执行路径**: 整体作为一个大件一次性重构 (四项全纳入一个 harness 任务, 不单独先发止血)。
- **超档策略**: 布局档位化后, widget 内容超出固定高度档时 = **截断 + 查看更多** (超出部分截断, 底部给 "查看更多" 入口跳详情页/弹层)。

### 验收意图 (从诉求提炼, 待 design 细化为可测条目)
- 拖拽流畅跟手 (帧率达标, 真跑 profile 实测)。
- 拖拽过程无内容变形 (任意尺寸 widget 互换均不缩放变形)。
- 新增 widget 后自动滚动到位并有视觉聚焦反馈。
- 布局为固定档位整数倍, 填空无竖向空隙; 超档内容截断 + 查看更多。
