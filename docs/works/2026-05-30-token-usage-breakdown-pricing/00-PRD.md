## 正文

用户先询问:

> 有没有什么网站或者 GitHub 项目公开了 API 或者一些归档的文件，罗列出了所有可供调用的模型的输入以及输出的价格。我想用它们来填充我们的 [花费]，这个功能里面的计价模型. 我印象中有一个项目叫 CC usage 有类似的功能，它是如何实现的？

随后补充:

> 还有一个点就是我们现在的用量统计是一个总数，它没有统计输入和输出。我们可以把这个东西 break down 出来吗？不仅仅是用量界面，还包括所有的 设计 token 显示的相关位置，例如会话里面

执行指令:

> 新建任务，开始设计

本任务按功能需求处理:
- 为本地用量统计增加 token 明细, 至少区分 input / output / cache / reasoning 中可从真实数据读到的部分。
- 更新所有显示 token 用量的位置, 不只限于 Usage 页面, 也包括会话列表、会话详情、Overview 最近会话等复用 token 展示的界面。
- 设计后续花费计价模型的数据来源、更新策略和缺失/不可信数据处理方式。
