## 正文
优化「能力」页面下的「hooks」功能。

当前 UI 展示的 5 个 hooks 生命周期基于 Claude Code 的生命周期创建。应用侧边菜单左上角支持切换 Agent 视角, 当前支持 Claude 和 Codex。当视角切成 all 或 codex 时, 这 5 个 hooks 在两个 agent 的生命周期之间有差异。

需要先联网检索, 调研 Codex 和 Claude 对 hooks 能力的支持, 以及生命周期差异。然后基于该功能建立一个更高一层的 hooks 生命周期抽象, 将两者整合到同一个界面展示。UI 需要展示这两者之上的抽象层, 而不是直接把某一家的生命周期当成统一模型。
