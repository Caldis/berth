## 正文
增加项目切换器, 让应用除了全局视图外, 还能切换到用户域或具体项目域。

范围:
- 定义 scope 模型: global / user / project。
- 应用壳提供固定项目切换入口, 不隐藏在设置深处。
- 切换后能够独立检视该项目的会话、配置、能力、hooks、skills、MCP、用量等内容。
- 梳理各页面数据源是否支持项目过滤。
- 与本地来源管理的后续整合保持兼容, 但不把本地来源迁移混入本任务。

验收:
- 用户可以在全局、用户域和项目域之间切换。
- 当前选择的范围会影响页面数据查询和配置展示。
- 项目切换器入口在应用壳中稳定可见。
- 不破坏已完成的 app shell 折叠、调宽、面包屑和窗口控制。
