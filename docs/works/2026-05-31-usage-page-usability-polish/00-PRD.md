# PRD 快照 (只读)

> 原始 PRD 的快照。任何阶段不回写。来源链接/页面 ID 记于此。

来源: 当前对话

## 正文

用户要求按优先级依次落地 Usage 功能后续体验改进:

1. 计价模式 tooltip: 解释自动、真实、估算三种模式。
2. token 结构条 tooltip: 细分 cache read/cache write/reasoning/unknown 等结构。
3. pricing gap JSON 示例加复制按钮。
4. 增加“数据口径”提示: 本地扫描与估算不一定等于供应商账单。
5. loading 使用 skeleton, 不要空白等待。
6. 错误态保留上一次成功数据, 标记正在显示上次结果。
7. pricing gap 的 JSON 示例默认收起。
8. 模型和项目列表支持点开查看组成。
9. 轻微状态变化动画。
10. 性能优化: 大数据量下 memo / 虚拟列表或分页。
11. 可访问性: segmented control role, 色块不只靠颜色表达。
