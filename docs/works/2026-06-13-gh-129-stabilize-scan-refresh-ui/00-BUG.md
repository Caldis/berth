# BUG 快照 (只读)

> 原始缺陷描述快照。任何阶段不回写。

来源:
- 用户反馈: 停留在某个页面时, 每隔四五秒导航栏显示“索引中”, 页面列表会刷新并闪一下。
- GitHub Issue: https://github.com/Caldis/berth/issues/129

## 复现步骤
1. 打开应用并停留在某个资产列表页, 用户举例为“月历页面”。
2. 不主动操作页面。
3. 观察约每隔 4-5 秒顶部/导航状态出现“索引中”, 下方列表同步刷新并产生闪烁。

## 期望 vs 实际
期望:
- 后台扫描或索引刷新不应清空或重建用户当前看到的 UI。
- 列表应保留旧数据作为 stale 数据, 只在有新增或删除项目时做稳定增量更新。
- 扫描周期、触发原因、是否可配置和性能成本应清楚可解释。

实际:
- 扫描状态频繁出现, 用户可见列表刷新并闪烁。
- 当前不清楚 4-5 秒扫描周期来自何处, 是否为有意设计, 是否有设置入口, 是否造成不必要开销。
