# 工程摩擦记录

> task: #6 Phase-2 messageKey 契约发版 (v0.4.6) — release CI test 红, golden 快照本机绿 / CI 红

## 发生阶段
4.0-verify / 5.0-archive 发版 (tag v0.4.6 → release.yml `test` job 失败, publish skip, 无 GitHub Release)

## 现象
#6 Phase-2 新建的两个 golden 快照 (engine `health-i18n-golden` + renderer `health-i18n-localize-golden`) 在**本机 (mac) 全绿** (lead 独立复跑 1311+124 也绿), 但 v0.4.6 release CI (ubuntu) `test` job 红 → publish 未跑 → 发版失败。差异两类:
1. **发现 id 的 hash 后缀派生自 os.tmpdir() 绝对路径**: fixture 用 `os.tmpdir()` 建临时目录 (mac `/var/folders/.../T` vs CI ubuntu `/tmp`), 而部分 check id 含 `hashString(绝对路径)` 后缀 (如 `...missing-import-1jcd9gj` vs `-1gx6kav`); snapshot 钉了 id → 跨 host 必不等。
2. **未 key 的原始 parser 错误文案随 Node/V8 版本变**: 无效 JSON/TOML fixture 触发的原始 `JSON.parse` 错误 (如 `Expected property name or '}' in JSON at position 2 (line 1 column 3)` vs `...at position 2`) 是 Node 版本相关串; snapshot 钉了它 → 跨 Node 版本不等。

根因: **快照钉了 host/Node 环境相关值**, 而快照在创作 host 上自然匹配, 故本机绿掩盖了不可移植性。

## 工程师介入动作
1. **归因 (非盲改)**: CI 失败 = golden snapshot mismatch; 比对 expected/received 锁定两类环境依赖 (路径派生 id-hash + Node 版本 parser 文案), 判定为快照可移植性缺陷 (非产品 bug — messageKey 契约代码正确)。
2. **修投影去环境依赖**: 两个 golden 投影 (1) 去掉 `id` (非契约, hash 依赖路径); (2) 改按 host-independent 复合键 (`[category,severity,agentId,i18nKeys,params]`) 排序, 不按路径派生 id 排; (3) 未 key 的 raw prose (parser/fs 错误) 占位 `<unkeyed>`; 只钉 i18n 契约 (keys+params) + **已 key 的** resolved prose。
3. **以 grep 证可移植 (非靠本机绿)**: 重生成快照后 grep 回归快照确认零 `"id":` / 零 `/var//tmp//private` 绝对路径 / 零 `position N (line..column..)` 类 Node 错误文案 → 才判定 portable。18 处 raw 错误已中和为 `<unkeyed>`。
4. 跳过失败的 v0.4.6 (未发布), 发 v0.4.7 (changelog 上一 tag..当前 tag 不丢 commit)。

## 应沉淀的上下文或规则
- **golden / snapshot 必须 host & Node 可移植**: 禁钉 (a) `os.tmpdir()`/绝对路径派生的 hash、id、路径串; (b) Node/V8 版本相关的 parser/fs 错误文案 (`JSON.parse`/`TOML`/`fs` error message 含 `position`/`line..column..` 等版本相关措辞)。
- **本机绿 ≠ CI 绿 (snapshot 专属陷阱)**: 快照在其创作 host/Node 上必然匹配, 独立复跑同机仍绿 —— 不可移植性只在异构 CI (ubuntu / 不同 Node) 现形。这类 release 阻塞型缺陷, 同机复验无论多严都测不出。
- **验收手段 = grep 回归快照, 不是再跑一遍**: 改/建 snapshot 后, grep 回归快照确认无绝对路径、无版本相关错误文案、无路径派生 hash/id; 快照只钉语义契约 (keys/params/已 key 的稳定 prose), 环境相关值占位或排除。
