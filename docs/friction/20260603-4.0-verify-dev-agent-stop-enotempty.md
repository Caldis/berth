# 工程摩擦记录

## 发生阶段

4.0-verify, GH-86 Settings 插件区真实 Electron 验收。

## 现象

执行 `pnpm dev:agent stop gh86-plugin-swr` 时返回 `ENOTEMPTY, Directory not empty`, 目标目录为系统临时目录下的 `berth-agent-dev/gh86-plugin-swr`。随后 `pnpm dev:agent status --id gh86-plugin-swr --json` 显示实例列表为空, `ps -p <pid>` 也确认原 agent-owned 进程已退出, 但 profile 子目录残留。

## 工程师介入动作

- 执行 `pnpm dev:agent guard after --id gh86-plugin-swr`, 用户 dev 保护检查通过。
- 执行 `pnpm dev:agent status --id gh86-plugin-swr --json`, 确认 agent 实例状态已清除。
- 执行 `ps -p 34515 -o pid=,ppid=,command=`, 确认原进程不再存在。
- 执行 `ls` 查看临时目录, 确认仅剩 profile 子目录。

## 应沉淀的上下文或规则

`dev:agent stop` 出现 `ENOTEMPTY` 时不能直接按仓库路径清理进程。需先用 `dev:agent status` 和进程查询确认 agent-owned 实例是否已退出, 再用 `dev:agent guard after` 确认用户 dev 未受影响。

## 建议的流程改进

`scripts/agent-dev-core.mjs` 的 stop 清理可在进程退出后增加短暂重试, 或把 profile 删除失败降级为 warning 并输出残留路径, 避免真实验收结束时把已停止实例误报为 stop 失败。
