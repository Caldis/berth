# 工程摩擦记录

## 发生阶段

4.0-verify, task_id=GH-10。

## 现象

Hooks 页面视觉验收时, 先按规则使用 `pnpm dev:agent start --id hooks-health-display-verify --json` 启动独立实例。该实例没有 `--remote-debugging-port`, 只能尝试 Win32 系统点击进入页面。当前 Windows 150% DPI 环境下, `SetCursorPos` + `mouse_event` 没有命中侧栏“能力”入口, 导致 renderer 路由操作卡住。

## 工程师介入动作

停止 `dev:agent` 实例并执行 `pnpm dev:agent guard after` 保护用户 dev。随后手动以独立 `--berth-agent-instance=hooks-health-display-remote`、独立 `--user-data-dir` 和 `--remote-debugging-port=9335` 启动 Electron, 用 CDP 切到 Hooks 页面, 再用 Win32 `PrintWindow` 截图验证真实窗口。

## 应沉淀的上下文或规则

Renderer 页面状态、路由切换、选中态这类验收需要稳定的 CDP 入口。`dev:agent start` 当前能隔离实例, 但不能配置调试端口; 在 Windows 高 DPI 下退回真实鼠标点击会增加坐标误差和误操作风险。

## 建议的流程改进

给 `pnpm dev:agent start` 增加可选 `--remote-debugging-port <port>` 或 `--debug-port <port>`, 并把端口写入 state。verify 阶段需要 renderer 交互时优先使用这个入口, 避免再手写 Start-Process 和临时 state 文件。
