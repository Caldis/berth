# 工程摩擦记录

## 发生阶段

implement

## 现象

用户已经多次要求小步频繁提交, workflow 中也已有相关规则, 但本轮实现完成后仍然把多个已验证增量堆到最后一次性提交。

## 工程师介入动作

用户明确指出该问题后, 补做提交, 并要求将该规则提升为最高优先级。

## 应沉淀的上下文或规则

已验证、边界清楚的增量必须小步频繁提交。完成一个可独立验证的子步骤并通过对应检查后, 立即只暂存自己相关文件、用 `git diff --cached` 核对 staged 集合、提交一次。

## 建议的流程改进

将小步频繁提交从“尽可能”改为“必须”, 并写入根 `AGENTS.md` 与 workflow 共享契约。archive / 收尾提交不能替代 implementation 过程中的小步提交。
