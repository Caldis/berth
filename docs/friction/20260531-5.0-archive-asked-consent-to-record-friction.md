## 应沉淀的上下文或规则
- friction 沉淀是 Agent 的**自主职责**, 默认动作链为: 识别可复用摩擦 → 检查 `docs/friction/` 是否已有
  相关记录 → 有则合并、无则新建 → 过 `pnpm harness:check` → 当轮事后向用户汇报。**不在此链中插入
  "是否要记录"的同意步骤**。
