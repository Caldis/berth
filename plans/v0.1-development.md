# Berth v0.1 Development Plan

## Tech Stack
- **Runtime**: Electron 33+ (electron-vite)
- **Frontend**: React 19 + TypeScript 5.7
- **UI**: shadcn/ui + Tailwind CSS 3.4 + lucide-react
- **State**: Zustand 5
- **i18n**: i18next + react-i18next (en/zh)
- **Router**: react-router-dom 7 (MemoryRouter)
- **Search**: MiniSearch
- **Storage**: better-sqlite3
- **File Watch**: chokidar
- **Testing**: Vitest + Playwright
- **Package Manager**: pnpm

## Development Phases

### Phase 1: Scaffolding ✅
- [x] Project config (electron-vite, TS, Tailwind, shadcn/ui)
- [x] Entry points (main, preload, renderer)
- [x] Shared types (Asset model)
- [x] i18n setup (en/zh)
- [x] GitHub private repo

### Phase 2: App Shell + Overview (Parallel Agents)
- Agent A: Layout (Sidebar, Titlebar, AppLayout, SearchDialog, ThemeProvider)
- Agent B: Main process (IPC handlers, adapter registry, Claude Code adapter skeleton)
- Agent C: Overview page + shared UI components (stat cards, badges)

### Phase 3: Module Pages (Parallel Agents)
- Agent A: Sessions module (list + detail)
- Agent B: Configuration > Instructions (Skills, Commands, Agents, etc.)
- Agent C: Configuration > Capabilities (MCP, Hooks, Plugins, Permissions)
- Agent D: Usage module + Settings page

### Phase 4: Core Engine (Parallel Agents)
- Agent A: Claude Code adapter (full scanner for all 25+ asset types)
- Agent B: Asset engine (parser, watcher, relation resolver)
- Agent C: Search index (MiniSearch integration)
- Agent D: SQLite storage layer

### Phase 5: Advanced Features
- Global search dialog (⌘K)
- Scope merge display

### Phase 6: Testing
- Unit tests (Vitest) for parsers, adapters, engine
- Integration tests for IPC + scanning
- E2E tests (Playwright) for all user flows

### Phase 7: Documentation + Release
- README with 5-min quickstart

- Build pipeline (macOS + Windows)
- GitHub release v0.1.0
