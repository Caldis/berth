# harness-0.1-continue — 继续已有任务

输入: 任务目录名、`task_id` (`GH-123`)、`#123` 或 issue URL (参数 $ARGUMENTS); 为空时列出 `docs/works/` 下所有未归档任务供选择。

步骤:
1. 定位任务目录: 先按目录名精确匹配; 再按 `task_id` / `issue.number` / issue URL 匹配 `INDEX.md`; 最后按 `{date}-gh-{number}-*` 匹配。读取 INDEX.md frontmatter。
2. 按 `phase` 路由:
   - explore → 执行 `.agents/workflow/1.0-explore.md`
   - design → 执行 `.agents/workflow/2.0-design.md`
   - implement → 执行 `.agents/workflow/3.0-implement.md`
   - verify → 执行 `.agents/workflow/4.0-verify.md`
   - polish → 执行 `.agents/workflow/3.1-polish.md`
   - blocked → 向用户展示 INDEX 中标注的待澄清项, 澄清后回 design
   - archive → 提示该任务已可归档, 执行 `.agents/workflow/5.0-archive.md`
3. 不重置已完成阶段的产物。

产出: 续跑当前阶段。
